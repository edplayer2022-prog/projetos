# FluencyAI

Dashboard responsivo de uma plataforma de aprendizado de inglês com trilha personalizada, práticas rápidas e acompanhamento de progresso.

## Executar localmente

O projeto não exige instalação de dependências. Inicie um servidor HTTP na raiz:

```bash
python3 -m http.server 4173
```

Depois, acesse `http://localhost:4173`.

## Funcionalidades

- Visão geral da próxima aula e progresso na trilha;
- Meta semanal e sequência de estudos;
- Atalhos para conversação, pronúncia e revisão;
- Indicadores de nível, XP, precisão e atividade;
- Navegação responsiva para dispositivos móveis;
- Feedback visual ao iniciar uma aula.
